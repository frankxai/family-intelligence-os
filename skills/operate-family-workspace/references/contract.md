# Operating contract
Boundary: public reusable code; private tenant records; private original vault; scoped indexes; per-member AI memory. A developer's ability to run an application is not permission to read the archive.
Adoption levels: template → identity/storage connected → scoped single-member pilot → restore/revocation proven → household rollout → trustee continuity drill.
Workflow receipt: run ID, tenant, authenticated actor, purpose, bounded scope, policy version, source refs, model/processor, status, cost budget, result refs, human review and idempotency key. Log opaque identifiers, never private text.
Adapter status is declared explicitly: guide, contract, example, implemented, deployed, verified. End-to-end compatibility requires tests against the chosen installed runtime, not a generic MCP claim.
