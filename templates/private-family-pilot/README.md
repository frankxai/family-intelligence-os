# Private family pilot

This template configures policy only. It contains no people, relationships, contact details, secrets, claims, or evidence.

## Circle model

- `self`: each person's default private area.
- `household`: explicitly shared current-household operations.
- `core_circle`: individually invited closest trusted people.
- `extended_family`: wider adult branches with low sensitivity by default.
- `descendants_guardianship`: guardian-managed descendants, nieces/nephews, and godchildren with age-transition review.
- `trusted_advisors`: purpose-bound and time-limited professional support.

Kinship, household, godparent, guardianship, and access are separate relationships. Never add a child or living relative to this tracked example. Create the real manifest in the encrypted tenant store only after identity, recovery, revocation, RLS, export, and restore tests pass.
