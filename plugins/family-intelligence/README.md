# Family Intelligence skill pack
Includes curate-family-knowledge, guide-family-learning, operate-family-workspace.
Portable Agent Plugins manifest and Codex compatibility manifest are supplied. This is a skills-only package; no remote MCP server, private data, fabricated OAuth endpoint or live connector credential is bundled.
Use the folder as a plugin source in a supported client. ChatGPT plugin upload/review is a separate product step; this package has not been submitted or published in the directory. Local skill copies are available under skills/.
A private MCP connector requires deployed resource-level policy, per-member OAuth and a tested revocation path. The existing runtime gateway is stdio, not a remote ChatGPT endpoint.
