# Learning contract
Fields: lesson ID; tenant; approved source IDs; family principle author/version; question; activity; reflection; age band supplied by guardian; scope; status=guardian_review; review actor and timestamp only when actually obtained.
Skills confer no tool authority. Resolve permissions from the deployment. Family values are proposals until members agree; a guardian-approved lesson is not a scientifically validated claim.
Example: source=approved family recipe; question=what should we preserve?; activity=cook with an adult and note one inherited technique; reflection=what would you pass on? No private names or health details are needed.
