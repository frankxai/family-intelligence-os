# Portable family workflow pack
Six bounded workflow definitions, no live private executor. Import n8n/family-review.manual.json to inspect a manual, inactive planning workflow with no network requests, credentials or family records.
Production adapters must supply trusted identity and one-operation authority, minimization, revocation, durable receipts, idempotency, cancellation and human decision gates. Budget values are proposed defaults, not measured production costs. Never schedule a private run from the public template.
