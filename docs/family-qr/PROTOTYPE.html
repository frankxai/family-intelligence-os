The front door

Identity, then permission.

Cloudflare Access protects entry. The application rechecks family membership and the specific record. Revoke a member or code without granting access to anyone who photographed it.

The wider web

Approved sources, narrow tools.

Prefer official APIs and exports. Isolate unfamiliar pages. Quarantine downloads. Website instructions cannot change permissions or make the AI reveal documents.

The things we keep

A copy you can recover.

Private storage, separate secrets, encrypted exports and a tested restore. A backup counts when you can recover from it.

Not configured

Visibility with trust.

Show which controls are on and what they record. Start with device health, known threats, permission changes and usage totals. Avoid blanket recording of private conversations. Content inspection is a separate decision with a visible scope.

No system can promise that attacks never happen. Production needs verified identity, resource checks, patched dependencies, minimal data collection and recovery evidence.

No real family records, credentials, external requests, browser monitoring or AI calls. Role switching illustrates the design; it is not authentication. Public code stays separate from private family data.
